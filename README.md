## Running the Project Locally

This project is a Django web application and is intended to be run locally for assessment.

1. Clone the repository.
2. Install the required dependencies.
3. Run the database migrations.
4. Start the Django development server.

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open the project in a browser:

```text
http://127.0.0.1:8000/
```

## Django Admin Access

Django Admin can be accessed at:

```text
http://127.0.0.1:8000/admin/
```

The admin account can be used to verify establishment and organisation accounts.
